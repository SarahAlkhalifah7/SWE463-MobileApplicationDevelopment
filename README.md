# Taskarro

Taskarro is a family task-management and reward app designed to help parents assign daily tasks, track their children’s progress, and encourage positive habits through stars, streaks, rewards, and achievements.

## Project Overview

Taskarro provides two experiences:

- **Parent Mode** for managing children, tasks, rewards, and progress.
- **Child Mode** for completing daily missions, earning stars, tracking streaks, and unlocking achievements.

## Features

### Parent Mode

- Welcome and mode selection
- Parent login and account creation
- Parent dashboard
- View and manage children’s profiles
- Add and edit child information
- View child avatars, stars, and streaks
- Create, edit, delete, and prioritize tasks
- Track pending and completed tasks
- Assign star rewards to tasks
- Manage available rewards
- View children’s task and reward progress

### Child Mode

- Personalized child home screen
- View daily missions
- Complete assigned tasks
- Track earned stars
- View current streak
- View upcoming rewards
- Explore a visual reward journey
- Track reward progress
- Complete weekly challenges
- View mystery reward progress
- View achievements and badges
- Unlock trophies for completing milestones

## Main Screens

The prototype includes the following screens:

1. Welcome / Mode Selection
2. Parent Dashboard
3. Children Profiles
4. Child Profile / Management
5. Task Management
6. Add / Edit Task
7. Rewards Management
8. Child Home / Daily Missions
9. Reward Journey / Progress
10. Streak and Weekly Challenges
11. Achievements / Trophy Room

## User Flow

### Parent Flow

1. The parent selects Parent Mode.
2. The parent creates an account or logs in.
3. The parent views the dashboard.
4. The parent adds or selects a child.
5. The parent creates and manages tasks.
6. The child completes assigned tasks.
7. The parent tracks stars, streaks, and progress.
8. The parent manages rewards.

### Child Flow

1. The child selects Child Mode.
2. The child views their personalized home screen.
3. The child completes daily missions.
4. The child earns stars.
5. The child progresses through the reward journey.
6. The child completes weekly challenges.
7. The child unlocks badges and achievements.
